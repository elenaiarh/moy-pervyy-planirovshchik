# План переноса АССИИ на VPS

## Цель

Перенести планировщик «АССИЯ» со статической версии на GitHub Pages в приватное серверное приложение на VPS:

- домен: `myplaning.platunova-fin.ru`;
- доступ только для одного пользователя;
- вход по логину и паролю;
- защита от перебора пароля;
- хранение задач в SQLite;
- чистая база без переноса старых данных из `localStorage`;
- ежедневные резервные копии SQLite на том же VPS;
- GitHub Pages оставить как демо.

## Принятые технические решения

- Backend: Node.js + Express.
- База: SQLite.
- Хранилище кода на VPS: `/opt/assiya`.
- База данных: `/var/lib/assiya/assiya.sqlite`.
- Вложения: `/var/lib/assiya/uploads`.
- Backup: `/var/backups/assiya`.
- Backend слушает только локально: `127.0.0.1:3020`.
- Запуск через отдельный `systemd`-сервис: `assiya.service`.
- Пользователь сервиса: отдельный Linux-пользователь `assiya`.
- Nginx: отдельный server-блок только для `myplaning.platunova-fin.ru`.

## Что нельзя трогать на VPS

До любых изменений выполняется read-only аудит. Без отдельного решения нельзя менять:

- чужие Nginx-конфиги;
- server-блоки других доменов и поддоменов;
- глобальный `/etc/nginx/nginx.conf`, если это не требуется критически;
- SSL-сертификаты других сайтов;
- существующие systemd-сервисы;
- директории других проектов;
- firewall/ufw, если он уже настроен;
- deploy-скрипты других сайтов.
