# Памятка: безопасное обновление АССИИ

Эта памятка нужна, чтобы обновлять планировщик `myplaning.platunova-fin.ru` без риска для других сайтов на сервере.

## Главное правило

АССИЯ изолирована от остальных продуктов:

| Что | Где |
| --- | --- |
| Код приложения | `/var/www/myplaning.platunova-fin.ru/` |
| SQLite-база | `/var/lib/assiya/assiya.sqlite` |
| Вложения | `/var/lib/assiya/uploads` |
| Backup | `/var/backups/assiya` |
| Systemd-сервис | `assiya.service` |
| Nginx-конфиг | `/etc/nginx/sites-available/myplaning.platunova-fin.ru` |
| Локальный порт | `127.0.0.1:3020` |

При обновлении АССИИ не трогать:

- `/var/www/buh.platunova-fin.ru/`;
- `/var/www/currency.platunova-fin.ru/`;
- `/var/www/checking.platunova-fin.ru/`;
- Nginx-конфиги других доменов;
- systemd-сервисы `currency-calculator.service` и `checking.service`;
- сертификаты других доменов.

## 1. Перед обновлением проверить текущее состояние

Подключиться к серверу:

```bash
ssh -i /Users/elena/.ssh/id_ed25519 elena.ai@85.198.102.39
```

Проверить сервисы:

```bash
systemctl is-active nginx currency-calculator checking assiya
```

Ожидаемый результат: все четыре сервиса `active`.

Проверить АССИЮ локально на сервере:

```bash
curl -fsS http://127.0.0.1:3020/health
```

Ожидаемый ответ:

```json
{"ok":true,"app":"assiya"}
```

Проверить публичный сайт:

```bash
curl --resolve myplaning.platunova-fin.ru:443:127.0.0.1 -I -L https://myplaning.platunova-fin.ru
```

Ожидаемо: сайт открывается и без входа ведёт на `/login`.

## 2. Сделать ручной backup базы перед важным обновлением

```bash
cd /var/www/myplaning.platunova-fin.ru
sudo runuser -u assiya -- /usr/bin/npm run backup
```

Backup попадёт в:

```text
/var/backups/assiya
```

Ежедневный автоматический backup уже настроен через:

```text
/etc/cron.d/assiya-backup
```

## 3. Сделать копию текущего кода перед заменой файлов

```bash
STAMP=$(date +%Y%m%d-%H%M%S)
sudo mkdir -p /opt/assiya.backups/manual-update-$STAMP
sudo cp -a /var/www/myplaning.platunova-fin.ru/. /opt/assiya.backups/manual-update-$STAMP/
```

Так можно быстро откатиться, если обновление окажется неудачным.

## 4. Обновить файлы приложения

Если обновляются только frontend-файлы, обычно достаточно заменить:

```text
/var/www/myplaning.platunova-fin.ru/src/app.js
/var/www/myplaning.platunova-fin.ru/src/styles.css
```

Если обновляется серверная логика, могут меняться:

```text
/var/www/myplaning.platunova-fin.ru/server/app.js
/var/www/myplaning.platunova-fin.ru/server/*.js
/var/www/myplaning.platunova-fin.ru/package.json
/var/www/myplaning.platunova-fin.ru/package-lock.json
```

После ручной замены файлов выставить владельца:

```bash
sudo chown -R assiya:assiya /var/www/myplaning.platunova-fin.ru
```

## 5. Проверить код перед перезапуском

```bash
cd /var/www/myplaning.platunova-fin.ru
sudo runuser -u assiya -- /usr/bin/npm run check
```

Если проверка не прошла — не перезапускать сервис, сначала исправить ошибку или откатить файлы.

Если менялся `package.json`, обновить зависимости:

```bash
cd /var/www/myplaning.platunova-fin.ru
sudo runuser -u assiya -- /usr/bin/npm ci --omit=dev
```

## 6. Перезапустить только АССИЮ

```bash
sudo systemctl restart assiya
sudo systemctl status assiya --no-pager
```

Не перезапускать другие сервисы без необходимости.

## 7. Проверить после обновления

Локальный health:

```bash
curl -fsS http://127.0.0.1:3020/health
```

Проверка через Nginx:

```bash
curl --resolve myplaning.platunova-fin.ru:443:127.0.0.1 -I -L https://myplaning.platunova-fin.ru
```

Проверка приватности API:

```bash
curl --resolve myplaning.platunova-fin.ru:443:127.0.0.1 -i https://myplaning.platunova-fin.ru/api/tasks
```

Ожидаемо без входа:

```text
HTTP/1.1 401 Unauthorized
```

Проверка Nginx:

```bash
sudo nginx -t
```

Если Nginx-конфиг не менялся, reload обычно не нужен.

## 8. Проверить, что другие продукты не пострадали

```bash
curl --resolve buh.platunova-fin.ru:443:127.0.0.1 -I -L https://buh.platunova-fin.ru
curl --resolve currency.platunova-fin.ru:443:127.0.0.1 -I -L https://currency.platunova-fin.ru
curl --resolve checking.platunova-fin.ru:443:127.0.0.1 -I -L https://checking.platunova-fin.ru
```

Ожидаемо: все отвечают `200`.

## 9. Откат, если что-то пошло не так

Найти последнюю копию:

```bash
ls -dt /opt/assiya.backups/manual-update-* | head
```

Остановить АССИЮ:

```bash
sudo systemctl stop assiya
```

Вернуть файлы из backup:

```bash
BACKUP_DIR=/opt/assiya.backups/manual-update-YYYYMMDD-HHMMSS
sudo rsync -a --delete "$BACKUP_DIR"/ /var/www/myplaning.platunova-fin.ru/
sudo chown -R assiya:assiya /var/www/myplaning.platunova-fin.ru
```

Запустить сервис:

```bash
sudo systemctl start assiya
sudo systemctl status assiya --no-pager
curl -fsS http://127.0.0.1:3020/health
```

## 10. Полезные команды диагностики

Логи АССИИ:

```bash
sudo journalctl -u assiya -n 100 --no-pager
```

Порты:

```bash
ss -tulpn | grep -E '3020|8787|8788|:80|:443'
```

Состояние backup-cron:

```bash
cat /etc/cron.d/assiya-backup
```

Список backup-файлов:

```bash
sudo ls -lh /var/backups/assiya
```
