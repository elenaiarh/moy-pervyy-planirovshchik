# АССИЯ

Локальный браузерный MVP планировщика задач «АССИЯ».

## Запуск

```bash
npm start
```

После запуска приложение будет доступно по адресу `http://localhost:5173`.

Данные хранятся в `localStorage` браузера. Это временный слой хранения: позже его можно заменить на серверный API без смены интерфейсной логики.
