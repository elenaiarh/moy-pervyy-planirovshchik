# АССИЯ

Приватный планировщик задач «АССИЯ»: PWA-интерфейс, серверная авторизация,
SQLite, резервные копии, вложения и Web Push.

## Локальный статический предпросмотр

```bash
npm start
```

После запуска приложение будет доступно по адресу `http://localhost:5173`.

В статическом режиме данные хранятся в `localStorage`. Этот режим используется
для предпросмотра и GitHub Pages-демо.

## Серверный запуск

```bash
cp .env.example .env
npm install
npm run server
```

Серверная версия хранит задачи в SQLite и требует вход по логину и паролю.
Подробности — в [server/README.md](server/README.md) и
[обновление-АССИИ.md](обновление-АССИИ.md).

Рабочий адрес: <https://myplaning.platunova-fin.ru>.
