# Концепция проекта «АССИЯ»

## 1. Общее описание

«АССИЯ» — локальный браузерный планировщик задач в формате веб-страницы. Продукт помогает пользователю спокойно планировать день, неделю и месяц, видеть баланс между рабочими и личными делами, не перегружаться и держать важные задачи в фокусе.

Приложение работает в браузере и хранит данные в `localStorage`. Пользователь может создавать задачи, распределять их по категориям, назначать клиентов для рабочих задач, отмечать выполнение, ставить напоминания и смотреть нагрузку в разных календарных представлениях.

## 2. Целевая аудитория

Основной пользователь — женщина, которая ведёт рабочие проекты, задачи по клиентам и личные дела. Ей важно видеть порядок в расписании, сохранять ощущение контроля и не превращать планирование в источник стресса.

## 3. Тон и характер продукта

Архетип продукта: заботливый стратег.

АССИЯ не давит на пользователя и не использует резкие предупреждения. Интерфейс говорит спокойно, поддерживающе и по делу: помогает заметить перегруз, увидеть свободные окна, мягко напомнить о задачах и зафиксировать прогресс.

## 4. Визуальная концепция

Интерфейс выполнен в спокойной ретро-эстетике с отсылками к бумажным блокнотам, печатным машинкам, гербовым печатям и мягким архивным карточкам.

Основные визуальные принципы:

- тёплый бежевый фон;
- графитово-синий основной текст;
- золотисто-медные акценты;
- пастельные цвета категорий;
- мягкие тени;
- аккуратные карточки;
- отсутствие агрессивных уведомлений;
- плавные анимации и спокойные переходы.

## 5. Текущая структура проекта

Проект реализован как локальное браузерное приложение.

Основные файлы:

- `index.html` — HTML-оболочка приложения;
- `src/styles.css` — стили интерфейса;
- `src/app.js` — логика приложения;
- `package.json` — служебный файл для запуска локального статического сервера;
- `README.md` — краткая инструкция по запуску;
- `favicon.svg` — иконка приложения.

## 6. Хранение данных

Все пользовательские данные хранятся прямо в браузере через `localStorage`.

Хранятся:

- список задач;
- даты задач;
- время начала и окончания;
- категории задач;
- клиенты рабочих задач;
- матрица фокуса;
- статусы выполнения;
- повторяемость;
- напоминания.

## 7. Основные сущности

### Задача

Задача — центральная сущность продукта.

Поля задачи:

- название;
- категория;
- клиент, если задача рабочая;
- дата;
- время начала;
- время окончания;
- признак «весь день»;
- повторяемость;
- матрица фокуса;
- напоминание;
- чекбокс заботы о перегрузе дня;
- статус выполнения;
- дата создания.

### Категория задачи

В текущей версии есть три категории:

- «Рабочая» — задачи по клиентам и проектам;
- «Я» — личные индивидуальные задачи;
- «Мы» — совместные, семейные или общие личные задачи.

### Клиент

Клиент используется в рабочих задачах как текстовое поле. По клиентам считается дневная нагрузка, а задачи можно фильтровать на экране дня.

### Матрица фокуса

Каждая задача относится к одному из четырёх квадрантов:

- важно + срочно;
- важно + не срочно;
- не важно + срочно;
- не важно + не срочно.

Матрица помогает пользователю видеть, где сосредоточена нагрузка дня.

## 8. Основной функционал

### Дашборд

Дашборд показывает общую картину выбранного дня.

На дашборде есть:

- логотип;
- текущая дата;
- поддерживающее приветствие;
- кольцевая диаграмма баланса задач;
- количество задач по категориям «Рабочая», «Я», «Мы»;
- блок просроченных задач;
- блок клиентов дня;
- матрица фокуса;
- переключатель «День / Неделя / Месяц»;
- мини-календарь на 7 дней;
- список задач в фокусе;
- плавающая кнопка добавления задачи.

### Экран дня

Экран дня показывает подробное расписание выбранной даты.

На экране дня есть:

- крупное текущее время;
- активные задачи;
- список всех задач дня;
- свободные промежутки «Воздух»;
- фильтр по матрице фокуса;
- фильтр по клиенту;
- блок клиентов дня с количеством задач;
- матрица фокуса с количеством задач по квадрантам;
- отметка задачи как выполненной;
- переход к редактированию задачи.

### Экран недели

Экран недели показывает задачи на выбранную неделю.

В недельном представлении есть:

- заголовок недели;
- стрелки переключения недель;
- кнопка возврата к текущей неделе;
- сетка дней недели;
- мини-список задач по каждому дню;
- цветные точки категорий;
- график нагрузки по дням.

### Экран месяца

Экран месяца показывает обзор выбранного месяца.

В месячном представлении есть:

- заголовок месяца;
- стрелки переключения месяцев;
- кнопка «Сегодня»;
- общее количество задач месяца;
- сводка по категориям «Рабочая», «Я», «Мы»;
- самый активный клиент месяца;
- календарная сетка месяца;
- количество задач в каждом дне;
- первые задачи внутри дня;
- цветные маркеры категорий;
- переход в подробный день по клику.

### Создание и редактирование задачи

Задача создаётся через модальное окно.

Пользователь может указать:

- название задачи;
- категорию;
- клиента для рабочей задачи;
- дату;
- время начала и окончания;
- режим «весь день»;
- повтор;
- матрицу фокуса;
- напоминание;
- предупреждение о перегрузе дня.

Существующую задачу можно открыть, изменить или удалить.

### Выполнение задач

Пользователь может отметить задачу выполненной. После выполнения задача становится визуально бледнее, перечёркивается и учитывается в прогрессе дня.

### Напоминания

Пользователь может включить напоминание для задачи и выбрать дату и время напоминания. В интерфейсе задачи показывается время будущего напоминания или отметка, что напоминание уже отправлено.

### Просроченные задачи

Если есть невыполненные задачи с прошедшим временем или датой, на дашборде появляется мягкий блок просрочки. При клике пользователь переходит к дню с просроченной задачей.

### Свободное время

Если между задачами есть промежуток больше 30 минут, экран дня показывает блок «Воздух» с подписью «Здесь ты можешь выдохнуть».

### Перегруз дня

Если пользователь добавляет больше 5 задач на день и включён чекбокс заботы, приложение показывает мягкое предупреждение о возможной перегрузке.

## 9. Сценарии использования

### Запланировать рабочую задачу

Пользователь нажимает кнопку добавления, выбирает категорию «Рабочая», вводит название задачи, клиента, дату, время, матрицу фокуса и сохраняет задачу.

### Запланировать задачу для себя

Пользователь создаёт задачу, выбирает категорию «Я», указывает дату и время. Задача отображается в календарях отдельным цветом и учитывается в балансе дня.

### Запланировать общую задачу

Пользователь создаёт задачу, выбирает категорию «Мы», указывает дату и время. Задача отображается отдельно от индивидуальных личных задач.

### Посмотреть нагрузку по клиентам за день

Пользователь открывает день и видит блок «Клиенты дня», где указано количество рабочих задач по каждому клиенту. По клику на клиента список задач фильтруется.

### Посмотреть задачи по матрице фокуса

Пользователь открывает день или дашборд и видит четыре квадранта матрицы фокуса. По клику на квадрант список задач фильтруется.

### Найти свободное окно

Пользователь открывает экран дня и смотрит блоки «Воздух», которые показывают свободные промежутки между задачами.

### Оценить месяц

Пользователь открывает вкладку «Месяц», видит дни с задачами, количество задач в каждом дне, баланс категорий и самого активного клиента месяца.

### Завершить задачу

Пользователь нажимает кнопку выполнения. Задача получает выполненный статус, визуально меняется и учитывается в общем прогрессе.

### Поставить напоминание

Пользователь открывает создание или редактирование задачи, включает напоминание, выбирает дату и время, затем сохраняет задачу.

## 10. Ключевая ценность

АССИЯ помогает не просто записывать задачи, а видеть структуру дня:

- сколько задач всего;
- какая часть дня рабочая;
- что относится к себе;
- что относится к общим делам;
- какие клиенты забирают внимание;
- какие задачи срочные и важные;
- где есть свободное время;
- не перегружен ли день.

Продукт создаёт ощущение спокойного контроля и бережного планирования.
